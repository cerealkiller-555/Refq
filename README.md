# رِفق 🤍

رفيق يرافقك في **تنظيم الحياة والتعلم والعمل والقلب**.

رِفق نظام متكامل يجمع: إدارة الحياة + إدارة التعلم + التخطيط الذكي + التقويم + الأولويات + التعافي + العلم والعمل والقلب — بحيث تشعر عند فتحه:
> *"أنا عارفة رايحة فين، عارفة أعمل إيه دلوقتي، ومش لازم أكون مثالية عشان أكمل."*

---

## الفلسفة

- **العلم ← فهم ← عمل ← أثر في القلب والسلوك**
- التطبيق **يسأل ويذكّر وينظّم** ولا يفتي ولا يحكم ولا يشخّص ولا يقيس القلوب بالأرقام.
- يوم فائت ليس فشلًا — الأداة الوحيدة هي **إعادة التوزيع بلطف**.
- النصوص الشرعية التي تظهر **من نصوص أدخلتها أنت بمصدرها** فقط.
- الراحة جزء من التخطيط، وليست عدوّه.

## التقنية

- **React + TypeScript + Vite** (واجهة)
- **Zustand** (حالة مركزية لكل domain)
- **Dexie / IndexedDB** (التخزين المحلي — طبقة Repositories الوحيدة التي تلمس DB)
- **PWA** (قابلية التثبيت على الجوال)
- **Vitest** (اختبارات المحركات والبيانات)

### Markdown = مصدر المعرفة

كل Note تُخزن `rawMarkdown` **كاملًا** (المصدر الوحيد للحقيقة) داخل IndexedDB، وكل المشتقات (tags/properties/wikilinks/backlinks) cache يُعاد بناؤها بالكامل عبر "Rebuild Index". التصدير يولّد ملفات `.md` فعلية قابلة للفتح في أي محرر.

## الأقسام الرئيسية

| القسم | الوظيفة |
|---|---|
| 🏠 اليوم | طاقة اليوم، أهم 3 أولويات، "ماذا أفعل الآن؟"، أسرع التقاط |
| 📅 التخطيط | المهام، التقويم (يوم/أسبوع)، أحداث ثابتة/مرنة، إعادة توزيع |
| 🎓 رحلتي | مسارات التعلم الست (جامعة/كورسات/دورات شرعية/كتب/قرآن/معرفة شرعية) |
| 🧠 المعرفة | ملاحظات Markdown، مجلدات، وسوم، روابط داخلية، backlinks، بحث |
| 🤍 القلب | أثر، فتش عن قلبك، وقفة أسبوعية، محاسبة اختيارية |
| ⚙️ النظام | الإعدادات، النسخ الاحتياطي (تصدير/استيراد)، حذف الكل |

## التشغيل

```bash
npm install
npm run dev       # تطوير
npm test          # اختبارات
npm run build     # بناء إنتاجي (PWA)
```

> **ملاحظة بيئة (Windows):** Node.js مثبت في `C:\Users\mnady\local\nodejs\...` وليس في PATH الافتراضي. إذا لم يتعرف `npm`، أضِف المجلد إلى PATH أو استخدم `cmd /c` مع `set PATH=...`.
